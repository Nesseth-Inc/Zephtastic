# BME680 environment telemetry

An optional Zephyr I²C node with compatible `bosch,bme680` and the alias `zt-bme680` owns one physical sensor. The fixture overlay binds address 0x76. Use the address and bus from the actual accessory assembly, and select the oversampling/filter options in `bme680.conf`. Pass `--extra-kconfig mt_only/tests/stock_bme680/bme680.conf` and `--extra-dtc-overlay` with `t096-bme680.overlay` on T096 or `bme680.overlay` on XIAO. The T096 fixture assigns address 0x76 exclusively to the BME680 and retains the optional probes at 0x77. Neither board's shipping overlay selects this accessory. Mesh environmental telemetry must be enabled before acquisition.

The devicetree node requires deferred initialization. The worker starts it only after telemetry is enabled and lets Zephyr’s one initial 197 ms conversion complete before the first retained sample. The stock acquisition profile uses 8× temperature, 2× humidity, 4× pressure, filter coefficient 3 (Zephyr filter choice 4 encodes register index 2), and the 320 °C heater with the Bosch-encoded 150 ms wait. The generic ZephCore poller and aliased environment reader skip this exact device, so their one-second sampling cannot trigger extra heater cycles. The upstream estimator keeps its original floating-point math and 24-byte serialized state. The freestanding build supplies the three-argument clamp in place of the C++ standard-library header. A completed conversion with either invalid gas or an unstable heater excludes gas resistance and follows the upstream IAQ carry rule.

Run `python3 mt_only/tests/stock_bme680/run.py --stock /path/to/meshtastic-firmware` from the repository. The runner verifies estimator source against the pinned Git object and compiles the 15 upstream estimator cases plus the ZT adapter and mocked worker owner under both enum ABIs with address and undefined-behavior sanitizers. The owner fixture checks actual platform register addresses/values, the gas validity flags, settings readback and retirement, and the normal environment-packet conversion. Hardware calibration, heating current and actual bus readings still require the accessory.

The baseline is stored in verified Zephyr settings under `mtxsensor/bme680`. Calibration retries transient reads and saves advanced warm-up progress across reboots. With a ready estimator and valid RTC, steady-state checkpoints are six hours apart. Both factory configuration and device reset stop the selected BME680 owner. The shared reset preference list also removes the calibration if a standard image handles the reset between two accessory boots.

The native transport test decodes BME680 gas and IAQ from USB, BLE, public RF and private endpoint replies on both board models, with generic environment channels enabled and disabled. It also checks gasless IAQ carry and rejects invalid gas and out-of-range IAQ.
