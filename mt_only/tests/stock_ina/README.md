# INA telemetry channels

Pinned Meshtastic `8e6a88d` samples INA219, INA260 and INA3221 for EnvironmentMetrics. INA226 has an environment accessor, but the stock environment producer never calls it. INA3221 provides one selected environment pair (stock default CH1) and three separate power channels. Set `CONFIG_MT_INA3221_ENV_CHANNEL` and `CONFIG_MT_INA3221_BAT_CHANNEL` to independently select the physical input, numbered 1–3. The declared device and shunt properties must match the board. Both consumers reselect the channel before reading it.

The stock power producer calls INA219, INA226, INA260 and INA3221 in that order, followed by MAX17048. The pinned INA219 and INA260 methods write EnvironmentMetrics members even on a power request. Their wire positions correspond to the third power channel. ZT assigns the measured values to typed PowerMetrics members explicitly. INA226 supplies CH1, and later INA3221 channels replace prior measurements field by field. Other ZephCore power sensors retain their enumerated channel. A declared `ina260` node with compatible `ti,ina260` and `zephyr,deferred-init` uses the same Zephyr driver for power, environment and configured battery selection. Its initialization checks both Texas Instruments identifiers before issuing the stock reset. The accessory fixture also selects distinct environment and battery inputs on INA3221.

Run `python3 mt_only/tests/stock_ina/run.py --stock /path/to/meshtastic --adafruit /path/to/Adafruit_INA260`. It compiles the pinned C++ handlers and the relevant sections of both stock producers, and compares their encoded telemetry against the ZT environment/power owner. It covers 16 board combinations, four independent producer-enable states, all three selectable channels, register-read failure and signed current across both enum ABIs. The INA260 register fixture exercises the production driver and checks all 65,536 ADC codes against Adafruit INA260 1.5.3. Physical calibration remains device-specific.
