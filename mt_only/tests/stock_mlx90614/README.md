# MLX90614 health telemetry

The `zt-mlx90614` alias selects an external `zephtastic,mlx90614` at 0x5a on a 100 kHz SMBus-compatible I²C controller. The accessory worker reads the factory SMBus address and four ID words and checks the PEC on each word. It reads object channel 1 only when health measurement is enabled and the sensor's emissivity is within 0.001 of the upstream 0.98 value. A bus failure, sensor error flag, zero object word, invalid identity or calibration mismatch suppresses the observation.

Stock registers MLX90614 in HealthTelemetry. Its sensor writes ambient and object values into the same nanopb union. The selected health variant carries object temperature. With this sensor alone, the ambient presence flag aliases the heart-rate flag and stock serializes zero bpm. ZT publishes object temperature and preserves measurements from genuine heart-rate/SpO₂ producers. The ordinary environment report continues to use its own devices. [Pinned stock health owner](https://github.com/meshtastic/firmware/blob/8e6a88d06f44cad26f1e8d7cd402939ccacb9b4c/src/modules/Telemetry/HealthTelemetry.cpp) · [Pinned stock MLX90614](https://github.com/meshtastic/firmware/blob/8e6a88d06f44cad26f1e8d7cd402939ccacb9b4c/src/modules/Telemetry/Sensor/MLX90614Sensor.cpp)

The acquisition path uses read-only SMBus transactions. Stock's Adafruit driver erases and programs the emissivity cell when its value differs. Melexis specifies different calibration steps for xAx/xBx and xCx devices, including a second interdependent cell for xCx and a sensor restart. Boards using this producer require a sensor previously configured for the correct emissivity using its model's procedure. The accessory overlay establishes a software build fixture. Physical population, calibration and hardware behavior still need bench evidence. [Manufacturer emissivity application note](https://www.melexis.com/en/documents/documentation/application-notes/application-note-mlx90614-changing-emissivity-setting) · [Manufacturer datasheet](https://www.melexis.com/en/documents/documentation/datasheets/datasheet-mlx90614)

The following fixture compiles the pinned stock health aggregator, MLX90614 sensor and Adafruit driver. It round-trips the donor and ZT protobufs, compares valid temperatures, records the stock EEPROM command sequence, and checks identity, PEC and error handling. It exercises periodic data, solicited health responses, feature disable/re-enable and freshness under both enum ABIs. [Pinned Adafruit 2.1.6](https://github.com/adafruit/Adafruit-MLX90614-Library/tree/8c32c95768e0960d7c27258b1d9bac16b8d7fdfc) · [Driver attribution and license](../../docs/licenses/Adafruit-MLX90614.txt)
